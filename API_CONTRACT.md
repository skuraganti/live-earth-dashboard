# API and integration contract

Base /api, app.main:app, GET /health. POST/DELETE/PATCH enforce loopback trusted Host and same-origin browser requests; no-origin CLI allowed. API responses plain JSON. All epoch timestamps in **milliseconds UTC** for UI, except explicit ISO metadata; coordinates latitude/longitude in degrees. Reject nonfinite numeric input.

- GET /api/state?until=<optional epoch ms>&min_mag=2.5 returns {mode:"current"|"replay",until,range:{start,end},events:[{id,type,lat,lon,depth_km,mag,place,time,updated,status,source_url,source_sha256}],weather:[{station,lat,lon,time,temperature_c,wind_kmh,description,source_url,source_sha256}],sources:[{id,url,last_attempt,last_success,observed_at,age_seconds,state:"fresh"|"stale"|"error"|"missing"|"clock_skew",error}],counts:{events,weather},poll_seconds}. range over stored quake event origins; until filters event origin <=time; weather selects latest captured report per station <=until. Current weather uses latest. Nulls stay null. Return at most 2000 events with total count/truncation field if needed.
- POST /api/refresh triggers one bounded refresh; returns source outcomes/state. Cooldown returns 429; in-flight returns 409. Source failures retain last-good entities and display errors, not successful fabricated observations. Sources are fixed original publisher URLs in PLAN/data manifest.
- GET /api/watches returns [{id,name,lat,lon,radius_km,min_mag,max_temperature_c,max_wind_kmh}]. POST accepts same minus id; optional thresholds null; required finite bounds lat[-90,90], lon[-180,180], radius 1..20000, mag[-2,10], name1..80. DELETE /api/watches/{id}. Creating watch evaluates local recent observed entities; match events <=24h old and only fresh provider data. Weather only when station within radius; no external calls for user coordinates.
- GET /api/alerts returns [{id,watch_id,watch_name,kind,evidence_id,message,event_time,created_at,acknowledged,source_url}]; POST /api/alerts/{id}/ack updates acknowledgment. Dedup by watch, kind and evidence; no new alerts from requesting replay.
- GET /api/snapshots returns bounded source retrieval metadata including URL, timestamp, hash and record count. Frozen input manifests under data/raw remain available for reproducibility. Runtime snapshots/attempts bounded (e.g. last32 per source), entities dedup persisted independently.

At startup initialize schema, then seed only recognized cached JSON/manifest filenames from EARTH_SEED_DIR (default data/raw, Docker /seed:ro), preserving original retrieved/provider timestamps; never relabel them newly fetched. EARTH_DB sets independent SQLite path. EARTH_POLL_SECONDS default300/min60/max86400, EARTH_AUTO_POLL default1 configurable0 for tests. If no seed, one actual bounded refresh is permitted; otherwise scheduler first refresh after interval or explicit manual call. One process/worker. Tests inject fetcher/clock or disable scheduler; synthetic cases labeled.

Event type is the publisher properties.type or unknown if absent. Only type=earthquake can produce an earthquake alert; other seismic events are preserved/type-labeled. Fixed canonical source URLs do not depend on seed availability. Exact original fetched bytes are retained for at most 32 snapshots per source in the independent SQLite volume; metadata indicates raw_preserved.
