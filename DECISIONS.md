# Decisions and observed corrections

The Python backend, ingestion, local interface and packaging were checked through domain tests, source review, Docker workflows and browser verification. Concrete defects and corrections are recorded below.

- **Small original feeds:** USGS plus NWS observations won over modeled Open-Meteo weather and a second NOAA aviation representation. Actual source inspection found one landslide, five sub-threshold reported magnitudes and markedly uneven station history/nulls; these remain visible rather than being invented or silently corrected.
- **SQLite and a single process:** appropriate for a bounded local notebook; a separate queue/database cluster would consume the constrained Docker VM without improving this workflow. A reentrant operation lock prevents alert commits from racing source transactions. Multi-worker deployment is unsupported.
- **Local basemap:** Leaflet's licensed map engine plus a frozen public-domain Natural Earth polygon layer avoid external tiles/accounts and remain available offline. The event table is the keyboard-accessible equivalent of mouse map markers.
- **Event-time replay:** original feed snapshots only establish what was captured. We explicitly reject the stronger historical-knowledge claim. Current source-health cards remain current during replay.
- **Conservative local alerts:** require recent, nonfuture observations from fresh sources; actual station radius is used. Null thresholds disable a kind, unknown/landslide types cannot trigger earthquake alerts, and replay never emits alerts. Alert acknowledgment is local.
- **Recovery:** old seeds originally overwrote newer source status and weather corrections. Seeding now only fills missing sources. Failed refreshes retain data, record source errors and remain retryable after cooldown.
- **Inspection changed implementation:** reviewer caught synchronous ASGI startup, missing refresh-time watch evaluation, incomplete database locking, post-buffer size checks, missing read Host protection and an unjoined poller. All were corrected and independently rechecked. A subsequent slow-drip probe showed 64KiB chunk aggregation delayed timeout enforcement; the final async fetch has an absolute deadline, unaggregated raw chunks and refuses compression. A malformed unit array now becomes a recorded PayloadError.
- **Verification changed tests:** several initial tests confused inclusive replay cutoffs, source age versus retrieval age, HTTP client refusal to serialize NaN, shared seeded fixtures and framework validation status. Corrections preserve contract assertions and add real concurrency, seed persistence, type and recovery regressions. No tests were relaxed to conceal an application failure.
- **Browser iteration:** the first axe invocation used an invalid top-level-await expression in the test harness; it was corrected. Acknowledged-alert opacity caused three contrast failures; opacity was removed and a visible border retained acknowledgment styling. Synthetic browser read failure remained separate from real source refresh. Screenshot inspection exposed a rapid Show→Fit animation race; those programmatic view changes are now immediate and the browser verifier asserts the fitted zoom.
